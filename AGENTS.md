# Repository guidance

This is a class project. Keep changes concise and straightforward.

- Work only within the requested scope.
- Do not add unnecessary comments, features, or documentation.
- Keep `DESIGN.md` focused on the software's role in the overall system.
- Before designing any magnetometer component, review the relevant source in `DESIGN.md` under “Magnetometer reference projects.”
- Ground component-design decisions in those sources and cite the source used; do not present an unsupported implementation choice as a project requirement.
- Keep commit history clean. I want one commit for a task. once done with the task, commit it. once commited, if there are changes, squahs them into the task's commit as long as the task's commit is the top one. if not ask for guidance.
